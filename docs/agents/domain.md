# Domain Notes

This is a single-context KOReader plugin.

Core terms:

- **Visible line**: a screen text box returned by KOReader for the current reader view.
- **Focus index**: the position of the currently focused visible line in the ordered line list.
- **Marker**: the optional visual cue drawn on the focused line.
- **Pattern**: the treatment applied to lines outside the focus window.
- **Placement mode**: a temporary interaction mode where a tap selects the nearest visible line.
- **Boundary action**: a request to move to the adjacent page when no line remains in the requested direction.
